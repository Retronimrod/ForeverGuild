# ForeverGuild

Guild roster, professions, crafting orders, and shared guild-bank snapshots for World of Warcraft Forever 1.60.1.

Copy the `ForeverGuild` folder into `Interface/AddOns` and type `/fguild`. The gear opens settings. The compass opens the in-game guide.

Guild data is exchanged through the in-game guild addon channel. Bank settings control automatic requests and sharing. A shared bank snapshot is visible to the whole guild, including members without direct vault access to a shared tab.

Recipe data uses LibProfessionDB data. Its MIT license is included in the addon folder.
